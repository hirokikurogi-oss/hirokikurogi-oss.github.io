## 配置ルール

- 縮小は `sips -z <高さ> <幅> <元> --out <先>` で行う（アスペクト比は 1206:2622 / 1320:2868 でほぼ同じ）
- 蔵書や物件が登録された状態で撮影する（空の画面では機能が伝わらない）
