## 撮り直しが必要な理由

- **02_scan.png** — シミュレータで撮影したため「Scanning is not supported on this device.」のエラーが表示されており使用不可。カメラのある実機で撮影する
- 配置済みの3枚も**表紙画像がすべてプレースホルダー**（書名・著者・出版社・ISBN は取得できているので、表紙 URL の取得または表示のみ失敗している）。
  「表紙画像を自動取得」と説明している以上、表紙が表示された状態で撮り直すのが望ましい

## 配置ルール

- 幅 900px に縮小して配置（`sips -Z 900 <file>`）
- 蔵書が登録された状態で撮影する（空の本棚では機能が伝わらないため）
